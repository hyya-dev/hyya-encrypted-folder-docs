## What it does

| | |
|---|---|
| 🔒 **Real encryption** | AES-256. Not a hidden folder or a passcode screen: every file is encrypted the moment it goes in, and so are the file names inside |
| 👆 **One check opens everything** | Face ID, Touch ID, your fingerprint, or your device passcode or password. No extra passwords to remember |
| ☁️ **Sync across devices** | Keep a folder in iCloud (iPhone, iPad and Mac) or in your own Google Drive (iPhone, iPad, Mac and Android). hYYa encrypts the folder on your device. Only encrypted files are uploaded |
| 📷 **Add your files** | Files on every platform. On iPhone, iPad and Android also photos and videos, a scanned document, or a file shared from another app |
| 🔑 **Recovery key** | One key that opens all your folders if you forget your passphrase |
| 🗑️ **Recently Deleted** | Recover deleted files and folders for 30 days |
| ✅ **Verify** | Check that every file in a folder still opens |
| 🎨 **Folder Styler** *(Mac)* | Give your Finder folders a colour and an emblem |

iCloud and Google Drive can see a folder's name, how many files it holds and their sizes and dates,
never what is inside.
