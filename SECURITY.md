# Security

## Report a security problem privately

If you find a security problem in hYYa Encrypted Folder (a way to read a folder without unlocking it,
to get around the lock, to reach your recovery key or Google sign-in, anything like that), please tell
us **privately**:

- here on GitHub, with **[Report a vulnerability](https://github.com/hyya-dev/hyya-encrypted-folder-docs/security/advisories/new)**
  (only you and hYYa can see it),
- by email to **[security@hyya.com](mailto:security@hyya.com?subject=Security%20issue%20%E2%80%94%20hYYa%20Encrypted%20Folder)**, or
- in the app: **Settings → About → Report a Security Issue** opens the same email.

**Please don't open a public issue for it.** Issues in this repository are public the moment they are
filed, and a problem described here before it is fixed puts every reader at risk.

Tell us, if you can:

- the device and system (for example: iPhone with iOS 26, a Mac with macOS 26, Android 16),
- the version of hYYa Encrypted Folder, shown on the app's page in the App Store or Google Play,
- what you did and what happened, and
- how to repeat it. Please don't send us your own private files.

## What happens next

We read every report. We reproduce the problem, fix it in an update for each platform it affects
(Mac, iPhone and iPad, and Android) and tell you when the fix is out.

If a problem is being exploited, we also report it as EU law requires, and tell users what it was and
what to do: here, in the update's release notes and on hyya.com.

## Which versions get fixes

Fixes ship as updates through the App Store and Google Play. The newest version on each store is the
one that receives them, so keep automatic updates on.

## Security advisories

None so far. When there is one, it is listed here with its date, the platforms and versions it
affects, the version that fixes it, and what you can do until you update.
